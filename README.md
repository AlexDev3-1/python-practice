# Python Practice Projects

A collection of CLI projects built while learning Python.

## Projects

### Calculator (`numbers.py`)
A terminal calculator that:
- Supports +, -, *, / operations
- Handles divide by zero errors
- Saves calculation history to a JSON file
- View past calculations anytime

### To-Do List (`Todo.py`)
A terminal to-do list that:
- Add tasks
- View all tasks with status
- Mark tasks as done
- Data persists in JSON

### Password Manager (`PasswordManager.py`)
A terminal password manager that:
- Add passwords by site and username
- View all saved sites
- Data saved to JSON file

## What I learned
- Loops and input validation
- File I/O with JSON
- Error handling with try/except
- Functions and separation of concerns
- enumerate() for indexed loops
- Working with lists of dictionaries

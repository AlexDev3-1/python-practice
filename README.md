# Python Practice Projects

A collection of CLI projects built while learning Python.

## Projects

### Calculator (`numbers.py`)
A terminal calculator that:
- Supports +, -, *, / operations
- Handles divide by zero errors
- Saves calculation history to a JSON file
- View past calculations anytime

## What I learned
- Loops and input validation
- File I/O with JSON
- Error handling with try/except
- Functions and separation of concerns
